# MIT 8103 Advanced Database Systems Portfolio

This repository contains the semester portfolio work for MIT 8103 Advanced Database Systems.

## Selected Case Study

NexaCart is the selected case study. It is a simulated e-commerce platform where customers browse products, place orders, make payments, submit reviews, and track deliveries. Administrators manage products, categories, inventory, and order fulfilment.

## Portfolio Areas

1. Portfolio 1 - Database Design and Modelling
2. Portfolio 2 - Query Processing and Optimisation
3. Portfolio 3 - Transactions and Concurrency
4. Portfolio 4 - NoSQL and Advanced Data Models
5. Portfolio 5 - Distributed and Cloud Database Exercise

## Current Status

[Portfolio 1](portfolio-1-database-design/README.md) contains the completed relational
design, PostgreSQL schema, sample data, constraint tests, evidence, and technical
documentation. Its validation suite covers 23 cases. Follow its setup instructions
to reproduce the database using Docker Compose and OrbStack.

[Portfolio 2](portfolio-2-query-optimisation/README.md) now contains SQL reports,
an isolated larger dataset, measured index comparisons and execution evidence.
Its implementation has been verified with captured screenshots.

[Portfolio 3](portfolio-3-transactions-concurrency/README.md) demonstrates
committed and rolled-back stock reservations, repeatable-read isolation, and an
atomic stock-reservation control under concurrent sessions. Its implementation is
verified; student screenshots are pending capture.

Portfolios 4-5 have not started. Their folders remain placeholders for later work
using the same NexaCart case study. The final 2-3 page LMS summary, individual
reflection, and assessor access check will accompany the completed semester
portfolio; the individual portfolios are not the full CA submission.
